These are the terms printed in `READ-ME-FIRST.txt`, inside the zip, under the heading "About this test build". The wording is the same. By running Starstuff you accept them.

- This is a test build. There is no warranty. You use it at your own risk.
- Keep backups of your captures. Starstuff reads your files and writes new ones. Never keep the only copy of anything in a folder you gave it.

Also from the same file, about privacy: Starstuff does not send your images, file names or settings anywhere. The README of this repository lists every service the program contacts and when.
