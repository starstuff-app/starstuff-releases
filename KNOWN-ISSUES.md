# Known issues in 0.7.0-beta.5

Checked against the code of this build. Tell us if you hit something that is not listed.

## Not included

| Item | What it means for you | What to do |
|---|---|---|
| Code signing | The program is not code-signed (that is separate from the signature on the update file), so Windows shows "Windows protected your PC" on every new build. | Click "More info", then "Run anyway". Check the SHA-256 fingerprint first (see the README). |
| Siril | Not included. Stacking needs it. | Install Siril 1.4 or newer from https://siril.org. In Settings, "Siril CLI Path" lets you point to it. |
| GraXpert | Not included. Optional. Without it a stack still finishes, but without the extra clean-up. | Install it from https://www.graxpert.com if you want it. |
| Video and timelapse export | Needs ffmpeg, which is not included. | Install ffmpeg so that it is on your PATH. |
| Telescope control | Not in the zip. It is an optional download inside the app. | On the Seestar tab press "Download Seestar support". See the README. |
| Updating in the program is new | Settings, About, Updates can find, download and install a newer build, and if you run 0.7.0-beta.4 it is the way to reach 0.7.0-beta.5. The team proved it on real builds, but how it behaves on your PC is still new to us. It refuses a build whose signature or fingerprint does not match. | Try it: press "Check now", then "Download and install", and tell us what the panel says at each step. If it fails, download the zip from this page and unzip it into a new folder (README, "How to update").

## Needs internet

Weather advice (Seestar tab), the cloud forecast in the Calendar tab, place search and the map in the observing-site picker, news feeds (Updates drawer), sky pictures (the Sky button in the Planetarium), plate solving (unless Siril has a local star catalog) and the telescope add-on need internet. Everything else works offline. If the sky pictures fail, the message mentions a "CDN". That means "no internet reached the sky picture server".

## Things you can run into

| Issue | What you see | Workaround |
|---|---|---|
| The scope keeps asking aloud for an app update | While Starstuff is connected, the Seestar says "Please update your app to the latest version" through its speaker about every ten minutes, and right after "Find scope". No phone is involved. Our guess is that the scope takes Starstuff's telescope library, which does not introduce itself the way the Seestar app does, for an old app; we have not proved that, and we have not yet checked whether the connection change of 0.7.0-beta.4 changed it. Outdoors at night this is a real nuisance. We are working on it. | Until it is fixed, turn the scope's speaker volume down in the Seestar app under the device settings before you connect Starstuff. Nothing needs updating on your side. |
| Scan & Prepare and Prepare Needed move files | Your raw `Light_*.fit` files go into a `lights` folder inside each target folder. This is by design. Nothing is deleted or renamed by default. | Keep a backup. Try one copied target folder first. The "Scan" button only looks. |
| The set-up cannot be skipped | You must give an archive folder, a latitude and a longitude to continue. | Any folder works. If it has no `01_Capture`, press "Create 01_Capture here". Enter your real latitude and longitude, or any numbers, and fix them later in Settings. |
| The archive drive is unplugged or renamed | The "Set up Starstuff" window opens again, because the folder does not exist. | Reconnect the drive, or give the new folder. |
| The data folder is on a drive that is not connected | Starstuff does not start as usual. It shows a screen that names the folder and offers only to choose a folder. It never starts with an empty folder in its place. | Connect the drive and start Starstuff again. A folder on a network or removable drive is the reason the set-up asks for a tick. |
| The phone app and Starstuff may not both fit on the scope | The Seestar accepts only a few connections at once. On our scope with firmware 9.31 the phone app was refused while Starstuff was connected, and the other way round. Since 0.7.0-beta.4 Starstuff keeps one connection to the scope, and opens a second one for pictures only while the Seestar tab or the camera picture in the Planetarium is on screen, or while a timelapse or star-trails capture is running, to leave room, but we have not yet seen both connected together on a real scope. | To hand the scope over, click the connection button at the top of the Seestar tab and press Disconnect, then open the phone app. To take it back, close the phone app's connection and press Connect in Starstuff. A run that is already on the scope keeps going while you swap. |
| Port 8100 is in use | The console prints "port 8100 is already in use" and Starstuff exits. There is no automatic fallback to another port. | Close the other copy, or set the `STARSTUFF_PORT` environment variable to another number such as 8101 before you start. |
| 2x drizzle has limits | 2x drizzle does not work with "Split LP into Ha + OIII" or on a mosaic, and it needs about 8 times the disk space a normal run needs for its aligned frames. Starstuff says so before the run starts. | Use a normal stack for those cases, or free disk space first. |
| Sub ratings are not calibrated | The 0 to 100 rating and the word on the Process tab, under Session history, are a first guess. | Treat them as a hint. Nothing is ever deleted because of a rating. Tell us when a rating looks wrong. |
| Tidy stack files moves your older stacks | On the Prepare tab, "Tidy stack files" first shows what would move. "Move" then puts each older stack and its files into a dated folder and renames them. Your subs in `lights` are not touched and nothing is deleted. It is new and has been tried on few archives. | Try it on a copy of one target folder first. "Undo" puts every file back. A file it cannot name is listed and left where it is. |
| Held mount moves are new and unproven on a real scope | With the telescope add-on, pressing and holding an arrow keeps the mount moving until you let go. The team has not yet checked the stop on release on a real telescope. A refused stop shows a warning. | Stay at the telescope. The "Stop slew" button and the Seestar phone app can stop a move. Tell us what happened. |
| An older mosaic still shows seams | The seam fix applies when you stack. | Re-stack the mosaic with the Mosaic preset. |
| Plate solving needs the internet unless Siril has a local star catalog | After a run, Starstuff asks Siril to plate-solve what it made, so each picture knows where in the sky it points. Siril uses its local star catalog if you have one installed and otherwise asks an online catalog. Offline, the solve fails: the run still finishes, the log shows a warning, and the processing summary says the stack is not plate-solved. | Nothing to do for the run. To solve later, connect to the internet (or install a local catalog in Siril) and press "Plate-solve this stack" beside "Rate this stack" in Check a finished stack. |
| An online catalog that hangs makes a run wait | If the online catalog takes the request and never answers, each solve waits up to 5 minutes (the stack itself, the GraXpert result when GraXpert ran, and the Ha and OIII stacks of a dual-band run, one after the other), and the solve inside the finish of the picture waits up to 20 minutes. After that Starstuff gives up on solving, finishes without it and writes a warning. | Wait for it, then solve later with "Plate-solve this stack". |
| A stack whose header has no binning entry may not be plate-solved | Siril 1.4.4 changed the pixel size in the header of a stack that had no binning entry (XBINNING) when it solved it. Starstuff checks every solved copy before it replaces a stack, so such a stack is left as it was, unsolved, and the log warns and names the card that changed. For the finished picture Starstuff puts the old pixel size back if the solve changed it, and logs a warning for each card. | Nothing is lost. Tell us if your Seestar stacks do this. |
| "Solve again" needs Siril 1.4.4 or newer | "Solve again" replaces a plate solution that a stack already has. With an older Siril, or one whose version Starstuff cannot read, it is refused with a message that says so. "Plate-solve this stack" on a stack with no solution does not need it. | Update Siril, or keep the solution the stack has. |
| Long text in a small camera tile is cut off | A small camera tile on the Seestar tab shows only the start of a long message. The whole text shows in full only as a tooltip when the mouse rests on it. | On a phone, which has no hover, tap the tile to put it on the stage. |
| After a restart with Disconnect remembered, loading the telescope add-on still sends a short search message | Starstuff stays disconnected after a restart if you pressed Disconnect, and makes no connection to the scope. The telescope add-on, when Starstuff loads it, still sends a short search message (a broadcast), repeated for about two seconds, on your home network, and it has no switch for that. | Nothing is needed: the message opens no connection to the scope. |
| Older nights say "Not rated yet" | Only nights that went through a Siril Register run since this feature arrived get a rating. | New runs are rated. Tell us if a new run is not. |

## Privacy note

Your photos, file names and settings are never uploaded. The report zip is saved on your PC and is sent only by you. The README lists every service the program contacts, and when.
